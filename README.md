# Code Mastery Repository for Beginners

Welcome to the training repository! This repository is designed for beginners to practice traversing, analyzing, debugging, and optimizing real codebases across three progressive levels.

---

## Levels Overview

### 📋 [Level 1: Documentation](level1/INSTRUCTIONS.md)
* **Language:** Python (`data_processor.py`)
* **Objective:** Read and analyze a comprehensive data processing library (`DataProcessor`) and write a production-ready `README.md` covering API specifications, setup, usage examples, and edge case handling.

### 🐞 [Level 2: Analyzing Code & Debugging Inconsistencies](level2/README.md)
* **Language:** C (`quicksort.c`)
* **Objective:** Analyze a complete implementation of Quicksort. Identify non-syntactic inconsistencies, style mismatches (naming conventions, indentation), missing memory deallocations, and edge-case errors without relying on standard compiler warnings.

### ⚡ [Level 3: Algorithm Optimization](level3/README.md)
* **Language:** C (`bellman_ford.c`)
* **Objective:** Traverse and optimize a Bellman-Ford graph shortest-path algorithm (>200 lines). Analyze time complexity bottlenecks and refactor the code/data structure for efficiency and clean memory management.

---

## Getting Started
Navigate to any level directory (`level1/`, `level2/`, or `level3/`) and follow the instructions in each level's instructions file.
